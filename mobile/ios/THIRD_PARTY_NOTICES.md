# iOS extraction dependency

XAN uses [YouTubeKit 0.4.9](https://github.com/alexeichhorn/YouTubeKit/tree/0.4.9), pinned to commit `e5b7d0396ce12bf3444f0d209e8436c83373b7af`, for native local YouTube audio extraction after the shared InnerTube resolver fails.

YouTubeKit is copyright Alexander Eichhorn and licensed under MIT. Its full license is in [YouTubeKit-LICENSE.txt](iosApp/ThirdParty/YouTubeKit-LICENSE.txt). The iOS project includes this license as an application resource. The optional third-party remote extraction service is not enabled.
